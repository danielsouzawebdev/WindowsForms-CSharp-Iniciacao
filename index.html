Windows Forms + C#

Primeiros passos com Windows Forms

Material prático para aprender interfaces gráficas utilizando C# e Visual Studio.

1. O que é Windows Forms?

Windows Forms é uma tecnologia do C# para criação de aplicações gráficas. Em vez de utilizar somente o terminal, o usuário interage com janelas, botões e campos de texto.

Console trabalha com texto. Windows Forms trabalha com componentes visuais.

2. Criando o projeto

  1. Criar novo projeto no Visual Studio
  2. Escolher Aplicativo Windows Forms
  3. Selecionar C#
  4. Escolher .NET 8 ou superior
